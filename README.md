**JavaScript Projects**

Below are a few web applications I developed using JavaScript to practice programming concepts and improve my front-end development skills.

**Projects**

Pizza Ordering System
Tic-Tac-Toe Game
Simple Calculator

**Pizza Ordering System**

This project allows users to build and customize a pizza by selecting different sizes and toppings. Once the selections are made, the application automatically calculates the total price and displays the final order.

**Tic-Tac-Toe Game**

A browser-based version of the classic Tic-Tac-Toe game for two players. The game randomly chooses which player goes first, lets each player select their symbol (X or O), and announces the winner with visual effects when the game ends.

**Simple Calculator**

A basic calculator built with JavaScript that performs the four main arithmetic operations: addition, subtraction, multiplication, and division. It features an easy-to-use interface designed for quick calculations.
